# 首尔两天购物手册

2026年11月20日、21日：圣水、江南、现代百货、明洞购物路线。

- `index.html`：行程、路线地图、特惠与品牌清单。
- `shopping.html`：独立购物页，14件商品、7个分类。按品类、预算、街区筛选，支持本地收藏、预算估算、图片放大与CSV导出。
- 购物页面脚本、样式与商品图全部内置，不使用外部CDN。
- 商品资料核查：2026-11-07。价格为韩国网页参考价，不承诺旅行日到店价。人民币系数为可编辑的预算假设。
- 小红书读取22篇笔记、206条一级评论、254条回复，商品卡采用16篇；型号和容量差异已注明，不计算全网好评率。
- 综合评分是编辑对本次行程的主观适配分，不是小红书官方评分。
- 登录凭据和原始采集数据不在网站中。
